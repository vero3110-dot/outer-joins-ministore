# outer-joins-ministore
Práctica
LEFT, RIGHT y FULL OUTER JOIN: analizando inventario y ventas de una tienda minorista

Propósito del ejercicio
En el mundo real los datos raramente están completos. Hay productos que nunca se vendieron, ventas registradas con IDs de productos inexistentes y registros huérfanos que ningún INNER JOIN te mostraría. En esta práctica vas a aprender a detectar exactamente esos casos usando las uniones externas de SQL, una habilidad crítica para cualquier analista que necesite auditar la calidad de los datos antes de construir un reporte.

Contexto
Sos analista de datos en MiniStore, una tienda minorista. El equipo de operaciones necesita respuestas a tres preguntas de negocio concretas que requieren cruzar el catálogo de productos con el historial de ventas, incluyendo los casos donde no hay coincidencia entre ambas tablas.
